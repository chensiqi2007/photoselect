1. Project Overview & Philosophy

PhotoSelect Desktop is an advanced, ultra-responsive RAW photo culling and digital asset management platform engineered by the URL Time team and open source contributors for commercial photographers, wedding shooters, sports action specialists, and wildlife birders.

With modern cameras outputting 45MP–61MP high-resolution imagery at rapid continuous burst speeds up to 120fps, photographers routinely capture thousands of photos during a single shoot. Traditional tools like Lightroom Classic suffer from painful catalog import bottlenecks, while legacy culling utilities lack hardware-accelerated focus verification, local eye-focus analysis, or modern video screening.

Core Pillars: Zero-Import instant loading, millisecond RAW+JPG synchronized pairing, WebGL 2.0 GPU focus peaking, 100% offline 468-point eye focus inspection, and bidirectional Adobe Lightroom XMP sidecar sync. 100% local processing with complete privacy.

2. Installation & System Requirements

Recommended Hardware Specifications

  • Operating System: Windows 10 (Build 1809+) / Windows 11 (64-bit); Linux (Ubuntu 22.04+, Fedora 38+, Arch Linux).
  • CPU: Quad-core or higher with AVX2 instruction set support (Intel 4th Gen Core+ / AMD Ryzen series).
  • RAM: 4GB minimum, 8GB–16GB recommended. Virtualized viewports keep memory footprint strictly constant regardless of shoot size.
  • GPU: Modern integrated or discrete graphics with WebGL 2.0 / DirectX 11+ / Vulkan support (for real-time shader peaking).

3. 3-Minute Quick Start Guide

  1. Open Media Folder: Click "Open Folder" or drag and drop your SD card volume or local directory directly into the application window.
  2. Blind Keyboard Culling: Thumbnails and preview viewports stream instantaneously. Use arrow keys → / ← to traverse, press 1–5 to rate, press P to flag pick, or press X to mark reject.
  3. Seamless Lightroom Export: When culling is complete, export ratings as .xmp sidecar files or simply open the folder in Lightroom Classic — your star ratings and flags appear immediately.

4. Zero-Import Architecture

Unlike legacy catalog-based systems that force photographers to wait through tedious copying, indexing, and thumbnail rendering stages, PhotoSelect eliminates ingestion latency:

  • Direct OS I/O Streaming: The Rust backend interfaces directly with low-level OS file handles, reading SD cards and NVMe drives concurrently.
  • Two-Level LRU Cache & Virtualized Viewports: Only images within the active viewport and pre-fetch margins occupy memory, guaranteeing rock-solid stability between 150MB and 350MB of RAM.
  • No Persistent Database Bloat: Zero multi-gigabyte cache databases left on your computer. Disconnect your storage card anytime with clean peace of mind.

5. Smart RAW+JPG Pairing

Shooting dual RAW+JPG is standard practice in wedding, event, and sports photography. Standard viewers display duplicates, requiring double the time to cull.

Unified Asset Cards: PhotoSelect detects matching base filenames (such as _DSC1024.ARW and _DSC1024.JPG) and pairs them into a single coherent entity.
  • 60fps Smooth Playback: High-resolution embedded JPG previews provide butter-smooth navigation and zoom.
  • Synchronized Asset Lifecycle: Ratings, flags, color tags, and deletions synchronize automatically between the paired RAW and JPG files.

6. Burst Clustering & Best Shot Recommendation

Action bursts can yield dozens of near-identical frames. PhotoSelect uses millisecond-accurate EXIF temporal analysis to automatically aggregate burst sequences.

SubSecTime Temporal Grouping

By inspecting SubSecTimeOriginal timestamps, frames captured within an adjustable threshold (default 0.8s) are collapsed into an interactive burst stack.

Best Shot AI Scoring

When inspecting a burst sequence, our local algorithm analyzes:

  • Eye Sharpness & Focus Accuracy: Verifies that critical facial landmarks are tack sharp.
  • Blink Detection Penalty: Identifies closed eyes or mid-blink expressions and docks score.
  • Subject Framing: The top-scoring frame receives the golden ★ Best Shot badge for split-second decisions.

7. Side-by-Side Dual Comparison

When choosing between closely matched expressions, press S to lock the current frame as the Benchmark Master:

  • Master vs Candidate: The benchmark remains static on the left while arrow keys navigate alternative candidate shots on the right.
  • Synchronized Pan & Zoom: Zooming in to 100% on one viewport synchronizes the coordinates and magnification on the other side simultaneously.

8. WebGL 2.0 Hardware Focus Peaking

Confirming critical depth-of-field focus without zooming to 100% is made possible via real-time WebGL 2.0 Sobel Edge Detection Shaders.

Press F anytime to overlay high-frequency edge highlights in Electric Blue, Emerald Green, or Ruby Red:

GLSL Focus Peaking Shader Implementation 
// WebGL 2.0 Focus Peaking Kernel Fragment Shader (Simplified)
#version 300 es
precision highp float;
in vec2 vTexCoord;
out vec4 fragColor;
uniform sampler2D uTexture;
uniform vec2 uTexelSize;
uniform vec3 uPeakingColor; // Electric Blue / Emerald Green / Red

void main() {
    float gx = -texture(uTexture, vTexCoord + vec2(-uTexelSize.x, -uTexelSize.y)).r
               + texture(uTexture, vTexCoord + vec2( uTexelSize.x, -uTexelSize.y)).r
               - 2.0 * texture(uTexture, vTexCoord + vec2(-uTexelSize.x, 0.0)).r
               + 2.0 * texture(uTexture, vTexCoord + vec2( uTexelSize.x, 0.0)).r
               - texture(uTexture, vTexCoord + vec2(-uTexelSize.x,  uTexelSize.y)).r
               + texture(uTexture, vTexCoord + vec2( uTexelSize.x,  uTexelSize.y)).r;
    float gy = -texture(uTexture, vTexCoord + vec2(-uTexelSize.x, -uTexelSize.y)).r
               - 2.0 * texture(uTexture, vTexCoord + vec2(0.0, -uTexelSize.y)).r
               - texture(uTexture, vTexCoord + vec2( uTexelSize.x, -uTexelSize.y)).r
               + texture(uTexture, vTexCoord + vec2(-uTexelSize.x,  uTexelSize.y)).r
               + 2.0 * texture(uTexture, vTexCoord + vec2(0.0,  uTexelSize.y)).r
               + texture(uTexture, vTexCoord + vec2( uTexelSize.x,  uTexelSize.y)).r;
    float edge = sqrt(gx * gx + gy * gy);
    vec4 baseColor = texture(uTexture, vTexCoord);
    if (edge > 0.35) {
        fragColor = vec4(mix(baseColor.rgb, uPeakingColor, 0.85), 1.0);
    } else {
        fragColor = baseColor;
    }
}

9. 468-Point Face & 100% Eye Focus Inspection

Blinking or soft eye focus ruins commercial group portraits. PhotoSelect features a Narrative Select-inspired multi-face inspector that runs 100% locally with zero cloud dependencies:

  • MediaPipe Face Landmarker WebAssembly: Real-time inference executed directly on local CPU / GPU hardware.
  • Automatic 1:1 Eye Crops: Locates every face in the frame and renders 100% scale thumbnails of both left and right eyes in a dedicated HUD tray.
  • Quantitative Openness & Sharpness Metric: Instant blink alerts prevent accidental delivery of compromised expressions.

10. Pro Camera Video Workflow & HUD

Modern hybrid cameras capture both stills and 4K/8K high-bitrate video clips (All-Intra, 10-bit 4:2:2).

HTTP 206 Partial Content Streaming

PhotoSelect's embedded Rust streaming server delivers instantaneous seeking with Range: bytes header support and 8MB predictive buffering. Heavy multi-gigabyte clips scrub with zero lag.

Darkroom Video HUD

  • Speed Controls: Smooth playback at 0.5x, 1.0x, 1.5x, and 2.0x.
  • Shortcut Navigation: Use Space to toggle playback, or press J / L to step ±5 seconds.
  • Live Rating & Culling: Apply star ratings and pick flags directly while video plays. Selected videos export automatically into an organized /VIDEO folder.

15. Technical Architecture & Building from Source

PhotoSelect Desktop combines high-performance native systems programming with modern web engineering:

  • Core Layer: Rust 1.78+ & Tauri 2.0 (Native OS windows, multi-threaded async file I/O, embedded HTTP 206 server).
  • UI Framework: Vue 3.5 (Composition API) + TypeScript 5.6 + Tailwind CSS 3.4.
  • Viewport Engine: WebGL 2.0 custom shaders for real-time focus peaking.
  • Local AI Engine: Google MediaPipe Face Landmarker WebAssembly offline model.

16. Frequently Asked Questions (FAQ)

Q: Why does PhotoSelect load much faster than Lightroom Classic?
A: PhotoSelect streams embedded camera preview JPEGs directly from storage cards using zero-copy Rust I/O and dynamic LRU garbage collection, avoiding time-consuming catalog database writes.
Q: What benefits do I unlock after signing in with a URL Time account?
A: Signing in automatically links your customized darkroom shortcuts, rating thresholds, and UI layouts across devices. Authenticated users also receive priority access to private betas for collaborative team proofing galleries and cloud asset review.
