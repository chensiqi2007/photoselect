1. 项目概述与设计理念

PhotoSelect Desktop 是由 URL Time 团队联合开源社区针对商业摄影师、独立摄影师、婚礼跟拍、体育赛事及生态鸟类摄影师打造的新一代极速摄影选片与数字资产管理平台。

在现代高像素（4500万至6100万像素）与高速连拍（20fps至120fps）普及的今天，摄影师单场拍摄动辄产出数千至上万张 RAW 文件。传统软件（如 Lightroom Classic 建立预览、Photo Mechanic 界面割裂、商业云端选片工具收费高昂且有隐私外泄隐患）已难以满足当下严苛的选片交付时效。

核心研发宗旨： 零导入即开即看、毫秒级 RAW+JPG 联动、WebGL 2.0 硬件着色器峰值对焦、纯离线人脸人眼 100% 特写、双图同屏裁决与 XMP 工业级侧车同步。100% 运行于本地，绝不上云！

2. 安装与环境部署

系统硬件要求

  • 操作系统： Windows 10 (1809 及以上) / Windows 11 (64-bit)；Linux (Ubuntu 22.04+, Fedora 38+, Arch Linux)。
  • 处理器 (CPU)： 建议 4 核及以上，支持 AVX2 指令集（Intel 4代酷睿及以上 / AMD Ryzen 全系列）。
  • 内存 (RAM)： 最低 4GB，推荐 8GB–16GB 或以上。面对万张连拍，虚拟滚动与 LRU 机制保证内存恒定。
  • 图形处理 (GPU)： 支持 WebGL 2.0 / DirectX 11+ / Vulkan 的现代核显或独立显卡（用于峰值对焦着色器实时计算）。

3. 3分钟极速上手暗房工作流

启动 PhotoSelect Desktop 后，只需三步即可完成专业初筛：

  1. 打开存储介质： 点击左上角「打开文件夹」或直接将 SD 卡卷 / 硬盘文件夹拖入窗口中央。
  2. 双星联动与全盲操浏览： 右侧照片网格即刻毫秒流式渲染。使用键盘方向键 → / ← 极速切片，按 1–5 打分，按 P 留用，按 X 淘汰。
  3. 一键同步与导出： 选片完成直接导出包含过滤评级的 .xmp 侧车文件，或直接在 Lightroom Classic 中打开该目录，所有打分标记 100% 完美复现。

4. 零导入 (Zero-Import) 直连架构

传统软件如 Adobe Lightroom Classic，在摄影师插入存储卡后必须经历“选择导入”、“建立目录 Catalog”、“渲染 1:1 预览”等繁冗流程，面对上千张 RAW 文件往往需要干等半小时甚至更久。

PhotoSelect 彻底颠覆了此传统范式：

  • 直连硬件文件系统： 核心层由 Rust 直接调用 OS 原生 I/O API，以异步并发线程池直读 SD 卡或 SSD 分区。
  • 双级 LRU 虚拟滚动机制： 界面仅渲染当前可见视口及上下预加载的卡片，无论加载 50 张还是 50,000 张巨幅照片，系统内存始终恒定在 150MB–350MB 之间。
  • 零持久化索引负担： 不在摄影师磁盘中生成数以 GB 计的臃肿数据库缓存，随时拔卡即走，洁净高效。

5. RAW + JPG 智能同名绑定 (Smart Pairing)

在专业商业跟拍中，双卡槽或机内“RAW+JPG”双格式记录是行业标配。传统选片软件往往将同名照片并列为两张，迫使摄影师重复筛选两次或手动编写过滤脚本。

双星合一机制： PhotoSelect 在扫描目录时，自动提取主文件名（如 _DSC1024.ARW 与 _DSC1024.JPG），并将其聚合为单一资产卡片。
  • 前台毫秒渲染： 优先利用相机内嵌的高品质全画幅 JPG 预览图进行丝滑 60fps 浏览与变换缩放。
  • 后台联动生命周期： 当你对卡片评级、标留、淘汰或重命名时，绑定的 RAW 原文件与 JPG 同步更新；生成 XMP 时同时注入原片关联。

五星评级与旗标管理

PhotoSelect 严格遵循国际影像行业评级规范。支持全盲操键盘快捷设定：按 0–5 瞬时赋予星级，按 P 标记为留用 (Pick)，按 X 标记为淘汰 (Reject)，按 U 撤销所有标记。所有状态均与底层的 RAW+JPG 实体保持毫秒级原子同步。

6. 连拍聚合与 Best Shot 推荐选帧

在体育竞技、鸟类生态与人像连拍中，单次快门触发往往产生 10–50 张微小姿态差异的照片。一张张翻看不仅极度损耗精力，更极易产生审美疲劳导致误删最佳瞬间。

SubSecTime 毫秒级快门时序分组

PhotoSelect 深度解析照片 EXIF 中的 SubSecTimeOriginal 高精度时序标签。若相邻照片拍摄时间差在摄影师设定的阈值（默认 0.8 秒）之内，系统自动将其折叠聚合为连拍序列堆栈 (Burst Group)。

Best Shot AI 综合打分推荐

在展开连拍组时，系统运用本地轻量算法综合评估画面：

  • 眼部锐度与焦点清晰度评分： 锁定主体眼睛对焦是否扎实。
  • 闭眼检测反向扣分： 识别人物眨眼、半闭眼瞬态并降低权重。
  • 构图与主体居中度： 组内最高分照片将被自动标配金色 ★ Best Shot 徽章，辅助摄影师 1 秒决断。

7. 双图联动同屏比对 (Dual Comparison)

当摄影师在两到三张极其接近的肖像或动作中犹豫不决时，快捷键 S 可快速将当前照片设为标杆基准图 (Lock Benchmark) 并开启双图同屏比对视图：

  • 左侧标杆，右侧候选： 切换方向键时，标杆图保持静止，右侧依次轮播候选图。
  • 视角与缩放联动： 在任意一侧拖拽放大 100% 检视睫毛或羽毛细节时，另一侧视图自动等比、同轴同步平移，毫发之差立判高下。

8. WebGL 2.0 硬件着色器峰值对焦 (Focus Peaking)

为了在不放大到 100% 的前提下迅速确认微单相机的焦点落点（是大光圈景深内主体对齐，还是不慎跑焦到了背景杂物），PhotoSelect 内置了工业级 WebGL 2.0 GPU 峰值着色器。

按下键盘快捷键 F，视口即刻无缝叠加高频边缘检测图层：

GLSL Fragment Shader (Sobel Operator Edge Detection) 
// WebGL 2.0 Focus Peaking Kernel Fragment Shader (Simplified)
#version 300 es
precision highp float;
in vec2 vTexCoord;
out vec4 fragColor;
uniform sampler2D uTexture;
uniform vec2 uTexelSize;
uniform vec3 uPeakingColor; // Electric Blue / Emerald Green / Red

void main() {
    float gx = -texture(uTexture, vTexCoord + vec2(-uTexelSize.x, -uTexelSize.y)).r
               + texture(uTexture, vTexCoord + vec2( uTexelSize.x, -uTexelSize.y)).r
               - 2.0 * texture(uTexture, vTexCoord + vec2(-uTexelSize.x, 0.0)).r
               + 2.0 * texture(uTexture, vTexCoord + vec2( uTexelSize.x, 0.0)).r
               - texture(uTexture, vTexCoord + vec2(-uTexelSize.x,  uTexelSize.y)).r
               + texture(uTexture, vTexCoord + vec2( uTexelSize.x,  uTexelSize.y)).r;
    float gy = -texture(uTexture, vTexCoord + vec2(-uTexelSize.x, -uTexelSize.y)).r
               - 2.0 * texture(uTexture, vTexCoord + vec2(0.0, -uTexelSize.y)).r
               - texture(uTexture, vTexCoord + vec2( uTexelSize.x, -uTexelSize.y)).r
               + texture(uTexture, vTexCoord + vec2(-uTexelSize.x,  uTexelSize.y)).r
               + 2.0 * texture(uTexture, vTexCoord + vec2(0.0,  uTexelSize.y)).r
               + texture(uTexture, vTexCoord + vec2( uTexelSize.x,  uTexelSize.y)).r;
    float edge = sqrt(gx * gx + gy * gy);
    vec4 baseColor = texture(uTexture, vTexCoord);
    if (edge > 0.35) {
        fragColor = vec4(mix(baseColor.rgb, uPeakingColor, 0.85), 1.0);
    } else {
        fragColor = baseColor;
    }
}

9. 468 点人脸人眼 100% 特写检视 (Eye Focus Inspection)

在婚纱人像、毕业大合影或多人商业广告拍摄中，摄影师最怕的事情莫过于在后期放大时才发现画面中心人物“闭眼”或“眼部脱焦跑焦”。

PhotoSelect 采用类似 Narrative Select 的直观检视方案，但实现了完全本地纯离线推理：

  • 内置 MediaPipe Face Mesh WASM 引擎： 零联网、零外部 API 请求，在本地 CPU / WebAssembly 环境中毫秒级解算人脸 468 个三维标志点。
  • 智能裁剪与锐度评分： 自动识别画面中所有人物面孔，并在画面右侧浮窗平铺展开每张面孔的左眼与右眼 100% 原始像素裁切框。
  • 开闭眼警告指示： 实时标示睁眼百分比与眼球反光点锐度，合影中有人眨眼一览无余，彻底杜绝翻车。

10. 专业相机视频全流程支持 (Pro Camera Video Workflow)

随着索尼 FX3/A7S III、佳能 R5 II、松下 S5 II 等微单“照片+视频双修”成为主流工作模式，摄影师的存储卡内往往交织着高码率 4K/8K 视频文件（如 .MP4、.MOV、.M4V、.MTS 等）。

HTTP 206 局部内容分块传输

PhotoSelect 桌面底层的 Rust 本地协议层内建了轻量级流媒体服务器，全面支持 Range: bytes 分块请求与 8MB 高速分块预读。对于数十 GB 的 All-I 4:2:2 10bit 视频原片，拖动时间轴进度条即可实现毫秒级即拖即播，零卡顿等待。

暗房级 Video HUD 控制台

  • 无级倍速快进： 支持 0.5x、1.0x、1.5x、2.0x 无级倍速播放。
  • 快捷寻帧： 支持 Space 播放/暂停、J / L 或 Shift+方向键 ±5 秒精准倒退与前进。
  • 边播边选同态打标： 播放视频时可随时按下 0–5 星级或 P/X 旗标，导出时自动归集于独立 /VIDEO 目录。

11. XMP 侧车生态与 Adobe Lightroom Classic 衔接

PhotoSelect 坚持“不绑架用户工作流”的开放生态理念。选片所有的星级评定、色标标记与留用淘汰状态，全部遵循行业标准的 Adobe XMP (Extensible Metadata Platform) 侧车规范。

12. URL Time 账号体系与商业专业版生态

PhotoSelect Desktop 深度接入 URL Time 统一账号中心。摄影师与工作室通过右上角「URL Time SSO」完成安全登录后，可无缝激活个人云端特权，实现跨设备选片偏好同步与云端资产协同。

账号中心与安全保障：
• 单点登录支持： 统一通过 login.urltime.cn 进行加密鉴权，无需额外注册繁复密码。
• 隐私安全隔离： 照片的本地初筛与人眼检测始终在摄影师本机处理，云端账号仅同步授权状态与用户配置。
• 多端漫游： 支持多台修图工作站（工作室台式机、移动笔记本）共用同一专业版账号。

15. 技术架构与本地编译构建

PhotoSelect Desktop 基于现代混合桌面架构打造：

  • 系统底层： Rust 1.78+ & Tauri 2.0（跨平台原生窗口、异步多线程文件系统与低开销 HTTP 206 服务端）。
  • 前端框架： Vue 3.5 (Composition API) + TypeScript 5.6 + Tailwind CSS 3.4。
  • 视口渲染： WebGL 2.0 原生 Shader 着色器（极速峰值对焦与色彩校正）。
  • 本地 AI 推理： Google MediaPipe Face Landmarker WebAssembly 本地推理模型。

问：为什么我的某些最新相机 RAW 格式加载很慢？
答：为了达到极致速度，PhotoSelect 默认优先提取原厂 RAW 内嵌的高清全尺寸预览流（毫秒级）。如果相机存储卡写入时关闭了内嵌预览，则会触发 LibRaw 全像素解码。建议在相机设置中开启高质量机内预览。
