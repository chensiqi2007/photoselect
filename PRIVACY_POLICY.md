## 繁體中文版

### 1. 簡介與核心承諾
PhotoSelect（由 URL Time 開發與發行）深知隱私對創作者與攝影師的重要性。我們堅守 **「本機優先、零資料收集 (Local-First & Zero Data Collection)」** 的核心設計理念。本隱私權政策旨在清楚向您說明本應用程式如何處理資料。

### 2. 資料收集與處理
* **零個人隱私收集**：PhotoSelect 不會收集、儲存、上傳、分析或出售您的任何個人身分資料（如姓名、電子郵件、IP 位址等）。
* **照片與元數據完全留存本機**：您在 PhotoSelect 中檢視、評分、標籤或匯出的所有相片檔案、RAW 原檔（Sony ARW、Canon CR3、Nikon NEF 等）及其 EXIF/拍攝參數，均只在您的電腦本機記憶體與硬碟中進行處理與快取，絕不透過網路上傳至任何雲端伺服器。
* **AI 與臉部偵測演算法**：本軟體內建之焦點偵測或臉部偵測均於本機端執行（On-Device Processing），不會產生或上傳生物識別特徵到遠端。

### 3. 系統權限用途說明
* **檔案系統存取 (runFullTrust / Local File Access)**：應用程式向 Windows 系統申請的讀寫權限，僅用於讓您自由選擇相片目錄、讀取高速快取、產生縮圖以及執行批次選片匯出。

### 4. 網路通訊與分析
* PhotoSelect 核心選片功能完全支援無網路離線運作。
* 本軟體未嵌入任何第三方廣告平台、追蹤代碼或使用者行為監控外掛。

若本隱私權政策有任何修訂，將於微軟應用商店更新頁面公布。如對隱私權有任何疑問，請聯繫發行者：

## English Version

### 1. Overview
PhotoSelect (developed and published by URL Time) values your privacy. We are committed to a **Local-First, Zero Data Collection** architecture. This Privacy Policy outlines our data handling practices.

### 2. Information Collection and Use
* **No Personal Data Collected**: PhotoSelect does not collect, track, store, or sell any personally identifiable information (PII).
* **Local Processing of Media**: All photos, RAW camera files (Sony ARW, Canon CR3, Nikon NEF, etc.), EXIF metadata, and database indexes are processed strictly on your local machine. No media files or previews are uploaded to any external or cloud servers.
* **On-Device Vision Analysis**: Any AI or face-detection helpers operate purely on-device using local inference models. No biometric templates or vectors are transmitted.

### 3. File System Permissions
* The application requests local file system access permissions (`runFullTrust`) solely to open directory dialogs, stream local RAW previews, create thumbnail caches, and export selected photos based on your explicit commands.

### 4. Third-Party Services & Telemetry
* PhotoSelect operates entirely offline for core culling workflows.
* It does not contain third-party tracking, advertising SDKs, or behavior monitoring code.

* **Publisher**: URL Time
* **Email**: support@urltime.com
